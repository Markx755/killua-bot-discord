# Killua Bot — ระบบ Voice 24/7

บอท Discord ที่ค้างห้องเสียงตลอด 24 ชั่วโมง ตั้งค่าผ่านคำสั่ง `/botvoice`

## วิธีติดตั้ง

1. ไปที่ https://discord.com/developers/applications → New Application → ตั้งชื่อ **Killua Bot**
2. แท็บ **Bot** → Reset Token แล้วคัดลอกโทเคน
3. แท็บ **OAuth2 → URL Generator** เลือก scope `bot` + `applications.commands`
   และสิทธิ์ `View Channels`, `Connect`, `Speak`, `Send Messages` แล้วใช้ลิงก์เชิญบอทเข้าเซิร์ฟเวอร์
4. คัดลอก `.env.example` เป็น `.env` แล้วใส่โทเคน
5. ติดตั้งและรัน (ต้องใช้ Node.js 18+)

```bash
npm install
npm start
```

## วิธีใช้

พิมพ์ `/botvoice` (ต้องมีสิทธิ์ Manage Server)

- เลือกห้องเสียงจากเมนู
- กด **เปิดระบบ** บอทจะเข้าห้องและอยู่ตลอด (หลุด/โดนย้ายจะกลับเข้าเอง)
- กด **ปิดระบบ** บอทจะออกจากห้อง
- กด **รีเฟรช** เพื่ออัปเดตสถานะ

การตั้งค่าเก็บใน `data.json` และจะเข้าห้องอัตโนมัติเมื่อรีสตาร์ทบอท

## โครงสร้างโค้ด

หนึ่งระบบ = หนึ่งไฟล์ใน `src/features/` (`voice` `stats` `antispam` `verify` `language` `images` `tools` `create` `trap` `announce` `antinuke` `onboarding`)
ข้อความ TH/EN แยกตามระบบที่ `src/texts/` ส่วนของที่ใช้ร่วมกันอยู่ที่ `src/` (`db.js` `emoji.js` `i18n.js` `ui.js` `log.js` `client.js`)
`index.js` มีหน้าที่แค่โหลดระบบทั้งหมดแล้วต่อเข้ากับบอท

```bash
npm start       # รันบอท
npm run check   # ตรวจไวยากรณ์ + ไฟล์ลับ + import ที่ลืม
npm test        # เทสต์ด้วย discord.js ปลอม (ไม่ต้องใช้โทเคน)
```

จะ push ขึ้น GitHub ดู [`docs/AGENT_PUSH_GUIDE.md`](docs/AGENT_PUSH_GUIDE.md)

## ระบบสถิติเซิร์ฟเวอร์

พิมพ์ `/สร้างระบบสถิติเซิฟเวอร์` บอทจะสร้างหมวด 📊 SERVER STATS พร้อมห้องเสียง 3 ห้อง (สมาชิก / ออนไลน์ / บอท) ที่คนเข้าไม่ได้ และอัปเดตตัวเลขทุก 10 นาที กดปุ่ม **ปิดระบบ** เพื่อลบห้องทั้งหมด

ต้องเปิดใน Developer Portal → Bot → Privileged Gateway Intents:
- **Server Members Intent**
- **Presence Intent**

และบอทต้องมีสิทธิ์ **Manage Channels**

## ระบบป้องกันสแปมและ Webhook

พิมพ์ `/ระบบป้องกันสแปมและwebhook` เพื่อเปิดแผงควบคุม

- **Anti-Spam** ส่งข้อความเกินกำหนดในเวลาที่ตั้ง จะถูกลงโทษ (delete / timeout 10 นาที / kick / ban) ข้ามคนที่มีสิทธิ์ Manage Messages
- **Anti-Webhook** webhook ส่งรัวเกินกำหนด จะลบ webhook และข้อความของมัน
- **Raid Mode** เปิดทั้งสองระบบและทำให้เกณฑ์เข้มขึ้น 2 เท่า
- `/setup-log` ตั้งห้องที่บอทส่งบันทึกการลงโทษ

ต้องเปิด **Message Content Intent** เพิ่มใน Developer Portal และให้บอทมีสิทธิ์ Manage Messages, Moderate Members, Kick Members, Ban Members, Manage Webhooks (ยศบอทต้องสูงกว่าคนที่จะลงโทษ)

## ระบบยืนยันตัวตน

พิมพ์ `/ระบบยืนยันตัวตน` แล้วเลือก **ยศ** ที่จะให้หลังยืนยัน, **ห้องยืนยันตัวตน**, **ห้อง log** จากนั้นกด **ส่งหน้ายืนยัน** บอทจะโพสต์หน้า Server Verification Gate พร้อมปุ่ม Verify / Why Verification? ในห้องที่เลือก

เลือก **รูปแบบยืนยัน** ได้ 3 แบบจากเมนูในแผง:
- **Button** กดปุ่ม Verify แล้วได้ยศทันที
- **Modal** กด Verify แล้วบอทส่งรหัส 5 ตัว (เห็นคนเดียว) ให้กดปุ่มแล้วพิมพ์รหัสในป๊อปอัพ ผิดเกิน 3 ครั้งต้องเริ่มใหม่
- **Website** กด Verify แล้วได้ลิ้งส่วนตัว เปิดแล้วตอบโจทย์บวกเลขง่ายๆ เพื่อรับยศ ต้องตั้ง `PUBLIC_URL` และ `PORT` ใน `.env` (ลิ้ง https ที่เข้าจากอินเทอร์เน็ตได้ เช่นทำด้วย cloudflared หรือ ngrok ชี้มายังพอร์ตของบอท)

- ยศของบอทต้องอยู่สูงกว่ายศที่จะให้
- ตั้งสิทธิ์ห้องเอง: ให้ @everyone เห็นแค่ห้องยืนยันตัวตน และให้ยศที่ได้หลังยืนยันเห็นห้องอื่นๆ

## ลบข้อความและให้บอทส่งข้อความ

ทั้งสองคำสั่งต้องมีสิทธิ์ Manage Messages

- `/ลบข้อความในห้องนี้` เลือกจำนวน 1-100 ลบข้อความล่าสุดในห้องที่พิมพ์คำสั่ง (ข้อความที่เก่ากว่า 14 วัน Discord ไม่ให้ลบ)
- `/ใช้บอทส่งข้อความ` เปิดฟอร์มให้พิมพ์ข้อความหลายบรรทัดและใส่ลิ้งภาพได้ เลือกห้องปลายทางได้ (ไม่เลือก = ห้องนี้) บอทจะไม่ปิง @everyone/@role ให้ เว้นแต่ผู้ใช้มีสิทธิ์ Mention Everyone เอง และจะบันทึก log ถ้าตั้ง `/setup-log` ไว้

## บอทสร้างห้อง

`/บอทสร้างห้อง` (ต้องมีสิทธิ์ Manage Channels) เปิดแผงที่เห็นคนเดียว เลือกหมวดหมู่ที่จะวางห้อง (หรือไม่เลือกก็ได้) แล้วกด **ห้องข้อความ**, **ห้องเสียง** หรือ **หมวดหมู่** จะมีฟอร์มให้กรอกชื่อ (ห้องข้อความใส่คำอธิบายได้ ห้องเสียงจำกัดจำนวนคนได้) บอทต้องมีสิทธิ์ Manage Channels

## เปลี่ยนภาษา TH/EN

`/เปลี่ยนภาษาเซิฟเวอร์` เลือก TH หรือ EN ตอนนี้ครอบคลุมระบบยืนยันตัวตน (รวมหน้ายืนยันที่ส่งไปแล้วจะอัปเดตตามภาษาให้) และข้อความทั่วไป

## ใส่ภาพให้แต่ละระบบ

ทุกแผงมีปุ่ม **ตั้งภาพ** กดแล้ววางลิ้งภาพ (ขึ้นต้นด้วย https://) ภาพจะแสดงใต้หัวข้อของแผง ปล่อยช่องว่างแล้วบันทึกเพื่อลบภาพ ระบบยืนยันตัวตนใช้ภาพนี้เป็นแบนเนอร์ในหน้า Verify (เช่นภาพ Welcome)

## ประกาศ @everyone

`/ประกาศ` (ต้องมีสิทธิ์ Mention Everyone) เลือกห้องได้ (ไม่เลือก = ห้องที่พิมพ์) แล้วกรอกหัวข้อ ข้อความ และลิ้งภาพ (ไม่บังคับ) บอทส่งแผงประกาศ UI V2 พร้อม **@everyone ทุกครั้ง** และบันทึกว่าใครประกาศอะไรไว้ในห้อง `Announcements` บอทต้องมีสิทธิ์ Mention Everyone ในห้องนั้น

## Anti-Nuke

`/antinuke` กด **เปิดระบบ** บอทตรวจ audit log: ถ้ามีคนลบห้อง 3 / ลบยศ 3 / แบน 4 / เตะ 4 ภายใน 10 วินาที จะ **แบนคนนั้นทันที** (แบนไม่ได้ = ถอดยศทั้งหมดแทน) แล้วแจ้งใน `︱・𝗔𝗻𝘁𝗶𝗡𝘂𝗸𝗲` ว่าใคร ทำอะไร และ Killua ทำอะไรไปบ้าง ข้ามเจ้าของเซิร์ฟเวอร์และตัวบอทเอง ห้อง/ยศที่ถูกลบแล้วไม่ถูกกู้คืนอัตโนมัติ ต้องมีสิทธิ์ View Audit Log, Ban Members, Manage Channels ปรับเกณฑ์ที่ `LIMITS` ใน `src/features/antinuke.js`

## ระบบต้อนรับเมื่อถูกเชิญ

เมื่อ Killua ถูกเชิญเข้าเซิร์ฟเวอร์ใหม่ จะทำงานตามนี้อัตโนมัติ

1. **DM ถึงคนที่เชิญ** (หาจาก audit log ถ้าไม่ได้ใช้เจ้าของเซิร์ฟเวอร์) ให้ยืนยันอีกครั้ง มีปุ่ม ยืนยัน / ไม่ต้องการ (บอทออกจากเซิร์ฟเวอร์) ถ้า DM ไม่ได้ จะส่งไว้ในห้องของเซิร์ฟเวอร์แทนและแท็กคนเชิญ
2. **แผงสอนตั้งยศ** ให้เปิด Administrator และลาก Killua ไปไว้บนสุดเท่าที่จะสุดได้ แผงแสดงสถานะสิทธิ์สด กด ยืนยัน เพื่อตรวจ ถ้ายังไม่ครบจะขึ้น "กำลังรอการอัปเดตสิทธิ์" แล้วอัปเดตเองเมื่อแก้ยศเสร็จ (หรือกด ตรวจสอบอีกครั้ง) กด ยกเลิก เพื่อหยุดตั้งค่า
   - เจ้าของเซิร์ฟเวอร์: ยศ Killua ต้องสูงกว่ายศของสมาชิกทุกคน (ไม่นับยศของบอทอื่น)
   - คนอื่น: สูงกว่ายศสูงสุดของผู้ตั้งค่าก็พอ (เพราะลากได้เท่าที่ยศตัวเองอนุญาต)
3. **สร้างหมวดหมู่ส่วนตัว `𝗞𝗶𝗹𝗹𝘂𝗮 - 𝗟𝗼𝗴𝘀`** (เห็นเฉพาะ Killua และเจ้าของเซิร์ฟเวอร์) พร้อมห้อง `╭・𝗔𝗻𝗻𝗼𝘂𝗻𝗰𝗲𝗺𝗲𝗻𝘁𝘀` `︱・𝗔𝗻𝘁𝗶𝗦𝗽𝗮𝗺` `︱・𝗔𝗻𝘁𝗶𝗡𝘂𝗸𝗲` `╰・𝗝𝗼𝗶𝗻𝗚𝗮𝘁𝗲` แล้วผูกกับ Anti-Spam / HoneyPot / Anti-Nuke / ยืนยันตัวตนให้เอง (ไม่ทับห้อง log ที่เคยตั้งไว้) ทุกขั้นตอนถูกบันทึกใน `Announcements` พร้อมประกาศต้อนรับ

คำสั่ง `/ตั้งค่าเริ่มต้น` ใช้เริ่มขั้นตอนตรวจสิทธิ์ใหม่ได้ทุกเมื่อ (ส่งทาง DM)

ลิงก์เชิญแนะนำให้ขอสิทธิ์ Administrator มาตั้งแต่แรก (แทน `YOUR_CLIENT_ID` ด้วยไอดีแอปของคุณ):

```
https://discord.com/oauth2/authorize?client_id=YOUR_CLIENT_ID&scope=bot%20applications.commands&permissions=8
```

ถ้าให้สิทธิ์ View Audit Log บอทจะหาคนที่เชิญเจอแม่นขึ้น

## ห้องดักสแปม (HoneyPot)

พิมพ์ `/antispam` (ต้องมีสิทธิ์ Manage Server) แล้วกด **เปิดระบบ**

- บอทสร้าง **ห้องดัก** ไว้บนสุดของรายการห้อง พร้อมข้อความเตือนและตัวนับ วันนี้/ทั้งหมด และสร้างหมวดส่วนตัว `𝗞𝗶𝗹𝗹𝘂𝗮 - 𝗟𝗼𝗴𝘀` (เห็นเฉพาะ Killua + เจ้าของ) ถ้ายังไม่มี โดยใช้ห้อง `︱・𝗔𝗻𝘁𝗶𝗦𝗽𝗮𝗺` เป็นห้อง log
- ใครพิมพ์ในห้องดัก (ที่ไม่ใช่ทีมงาน) ข้อความจะถูกลบทันที บัญชีถูกแบน **3 วัน** พร้อมลบข้อความของบัญชีนั้นย้อนหลัง 24 ชั่วโมง และปลดแบนให้เองเมื่อครบ (บอทเช็คทุก 1 นาที และตอนเปิดบอท)
- ทุกเคสที่ตรวจพบ Killua จะแจ้ง log (UI V2) ว่าทำอะไรไปบ้าง: ลบข้อความ / แบน 3 วัน / ตั้งปลดแบนอัตโนมัติ
- ในห้อง log ทุกเคสมีปุ่ม **ปลดแบน** และ **เพิกเฉย** (เพิกเฉย = ปิดปุ่มและปล่อยให้แบนต่อจนครบกำหนด) ต้องมีสิทธิ์ Ban Members ถึงจะกดได้
- ไม่แบนเจ้าของเซิร์ฟเวอร์ และคนที่มีสิทธิ์ Administrator / Manage Server / Ban Members / Manage Messages
- กด **ปิดระบบ** จะลบห้องดัก แต่เก็บห้อง log ไว้ เปิดใหม่ก็ใช้ห้อง log เดิม
- ตั้งภาพที่ปุ่ม **ตั้งภาพ** ภาพจะขึ้นทั้งในแผงและในห้องดัก

บอทต้องมีสิทธิ์ **Manage Channels, Ban Members, Manage Messages, View Channels, Send Messages** และยศของบอทต้องสูงกว่ายศของสมาชิกที่จะแบน

ปรับจำนวนวันที่แบนได้ที่ค่า `TRAP_DAYS` และช่วงลบข้อความย้อนหลังที่ `TRAP_PURGE_SECONDS` (สูงสุด 7 วัน) ในไฟล์ `src/features/trap.js`

## อิโมจิในแผง

อิโมจิทั้งหมดอยู่ที่ไฟล์ `src/emoji.js` สองตาราง: `EMOJI` คืออิโมจิของเซิร์ฟเวอร์ (ชื่อ + ไอดี) และ `E` คือการจัดว่าตัวไหนไปอยู่ตรงไหนของแผง อยากสลับตัวไหน แก้ฝั่งขวาของ `E` ที่เดียว (รูปแบบ `<:ชื่อ:ไอดี>` หรือ `<a:ชื่อ:ไอดี>` สำหรับอิโมจิขยับ)

- บอทต้องอยู่ในเซิร์ฟเวอร์ที่มีอิโมจิเหล่านั้น และมีสิทธิ์ **Use External Emojis** ในห้องที่ส่งข้อความ (ถ้าอิโมจิอยู่คนละเซิร์ฟเวอร์กับห้องที่บอทส่ง)
- ชื่อห้องสถิติใส่อิโมจิกำหนดเองไม่ได้ (Discord ไม่อนุญาต) จึงยังเป็นอิโมจิปกติ

## ถ้าบอทเข้าออกห้องเสียงวน

สาเหตุที่พบบ่อยคือ `@discordjs/voice` เวอร์ชันเก่า (0.18 ลงไป) ไม่รองรับการเข้ารหัสเสียงแบบ DAVE ที่ Discord บังคับใช้ ทำให้ถูกตัดการเชื่อมต่อซ้ำๆ แก้โดยอัปเดตแล้วติดตั้งใหม่

```bash
rm -rf node_modules package-lock.json
npm install
```

ต้องใช้ Node.js 24.17 ขึ้นไป ถ้ายังหลุด ให้ใส่ `DEBUG_VOICE=1` ใน `.env` แล้วดูสถานะที่บอทพิมพ์ออกมา

## โฮสต์ 24/7
